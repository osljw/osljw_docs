
# 声音

声音的特征
- 音调
    - 和频率有关， 频率高音调高
    - 乐器（空气柱越短，线越细，线越短，开口越薄，一般产生的频率越高，声音音调越高）
- 响度
    - 和振幅有关，振幅大响度高
    - 同一种物质，震动幅度不同，距离声源距离不同，会影响响度
- 音色
    - 和谐波/共振峰有关
    - 不同物质，音色不同


频率是音符的高低，响度是声音的大小，音色就是区分同一个音符由小提琴还是钢琴发出的关键。

人声音色特征：
- 基频（Fundamental Frequency, $f_0$）—— 声带振动，常说的“嗓音粗细”。男性通常在 $85Hz - 155Hz$，女性在 $165Hz - 255Hz$。
- 共振峰（Formants）—— 腔体形状， 每个人的声道长度、口腔形状、鼻腔大小都不同。物理本质：声音在声道中发生共振产生的频率峰值。
- 泛音列（Harmonics）—— 声音颗粒感， 沙哑感：声带闭合不全产生的气流声（噪声）。清脆感：高频泛音丰富。


# 人对声音的感觉

人类的听觉范围为20Hz～20000Hz，即20hz~20kHz，最敏感的是1000hz~3000hz之间的声音。低于人类听觉范围的叫做次声波，高于这个范围的叫做超声波。
